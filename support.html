遇到问题？先看下面常见问题，没解决就发邮件给我，通常在 3 个工作日内回复。

1. 数据存在哪里？换手机 / 卸载会不会丢？

所有数据（照片、体重、饮水、戒断记录）只保存在你的设备本地，没有账号、没有云端。卸载 App 会一并删除全部本地数据且无法恢复，请在卸载前使用「设置 → 数据与隐私 → 导出备份」。

换手机请先在旧机导出备份，再在新机导入。

2. 为什么拍照引导框对不齐？

拍照页面有引导框辅助构图，建议在光线均匀、背景简单的环境拍摄，尽量保持与上一次相同的角度与距离，对比会更直观。你也可以在「看变化」里任选两个时间点做对比。

3. 订阅了 Pro 但没有生效？

  • 确认 App Store 扣款成功后，点付费墙页面底部的「恢复购买」；
  • 订阅状态读取自你的 Apple ID，跨设备需要登录同一个 Apple ID 并恢复购买；
  • 如果是家庭共享成员，需要家庭组织者开启了「购买项目共享」。

4. 如何取消订阅或退款？

订阅为自动续期。取消请前往 设置 → Apple ID → 订阅；取消后权益保留至当前订阅期结束。退款请通过 App Store「报告问题」页面申请，我们无法直接办理退款。

5. 身体数据是准确的吗？

BMI、体脂预估、每日饮水量均由公开公式推算，属于估算值，不构成医疗建议。如有健康问题，请咨询执业医师。

6. 数据导出的备份加密了吗？

导出备份可选加密（设置 → 数据与隐私 → 导出备份）。请务必牢记你设置的密码，密码丢失后备份无法解密，我们也无法帮你找回。
