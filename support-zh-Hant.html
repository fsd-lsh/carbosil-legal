遇到問題？先看下方常見問題，若未解決請寄信給我，通常 3 個工作天內回覆。

1. 資料存在哪裡？換手機 / 解除安裝會不會遺失？

所有資料（照片、體重、飲水、戒斷紀錄）只保存在你的裝置本機，沒有帳號、沒有雲端。解除安裝 App 會一併刪除全部本機資料且無法復原，請在解除安裝前使用「設定 → 資料與隱私 → 匯出備份」。

換手機請先在舊機匯出備份，再在新機匯入。

2. 為什麼拍照引導框對不齊？

拍照頁面有引導框輔助構圖，建議在光線均勻、背景簡單的環境拍攝，盡量與上次保持相同角度與距離，對比會更直觀。也可以在「看變化」任選兩個時間點做對比。

3. 訂閱了 Pro 但沒有生效？

  • 確認 App Store 扣款成功後，點付費牆頁面底部的「還原購買」；
  • 訂閱狀態讀取自你的 Apple ID，跨裝置需登入同一個 Apple ID 並還原購買；
  • 若是家庭共享成員，需要家庭組織者開啟「購買項目共享」。

4. 如何取消訂閱或退款？

訂閱為自動續期。取消請前往 設定 → Apple ID → 訂閱；取消後權益保留至目前訂閱期結束。退款請透過 App Store「回報問題」頁面申請，我們無法直接辦理退款。

5. 身體數據準確嗎？

BMI、體脂預估、每日飲水量均由公開公式推算，屬於估算值，不構成醫療建議。如有健康問題，請諮詢執業醫師。

6. 匯出的備份有加密嗎？

匯出備份可選加密（設定 → 資料與隱私 → 匯出備份）。請務必牢記你設定的密碼，密碼遺失後備份無法解密，我們也無法幫你找回。
